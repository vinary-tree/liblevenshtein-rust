## Why the train advanced

RC.2 immutable-tag validation found an invalid Cabal file in libdictenstein:
the conformance test suite's `build-depends` omitted the comma after
`vinary-tree-interop >=4 && <5`. `cabal check` and the Hackage candidate job
both rejected the source. RC.2 tags therefore remain immutable and rejected.

The RC.3 correction adds the missing delimiter, constrains the synchronizer so
its version rewrite cannot consume dependency-list punctuation, and adds an
exact dependency-boundary invariant. The release audit also runs `cabal check`
against every maintained Haskell descriptor before any RC.3 tag is created.
No RC.2 tag or registry byte is overwritten.

## Validation and publication order

The RC.2 window proved that registry-shaped downstream jobs cannot precede
their exact upstream versions. RC.3 therefore advances through these hard
barriers:

1. validate, publish, and independently verify every authorized interop
   coordinate, including its crate and scoped npm contract;
2. validate libdictenstein after interop resolves, then publish its crate and
   non-JavaScript bindings while retaining its staged npm facade;
3. validate and publish the liblevenshtein crate and non-JavaScript bindings
   after libdictenstein is public;
4. validate and publish the lling-llang crate, then the duallity crate, against
   the exact public Rust graph;
5. validate and publish the shared runtime npm package after the Rust graph and
   scoped interop are public;
6. publish and verify the four staged scoped facades against that runtime,
   install and exercise all scoped packages together, then normalize their npm
   tags; and
7. publish the unscoped compatibility facade under `next` only, proving that
   `liblevenshtein@latest` remains `2.0.4`.

Every registry dispatch uses `refs/tags/v4.0.0-rc.3` and a protected
environment restricted to `v*` tags. A dependency-order failure is rerun only
after the exact missing coordinate has passed public read-back; a source or
package defect rejects RC.3 and advances to another unused candidate.
