# CBC claim, instance, and enforcement matrix

This matrix serves pgmcp task `cbc-01-matrix` and covers **all 98 downstream task leaves** in milestones M02–M08 of epic `metric-automata-cbc-theory` (#8567) at this snapshot. Task IDs are stable anchors; pgmcp remains authoritative for task status and dependencies. The [formal verification manifest](FORMAL_VERIFICATION_MANIFEST.tsv) remains authoritative for file-level verification status. This matrix is the claim-level crosswalk, not a second proof registry. Its [dependency diagram source](../diagrams/architectures/cbc-proof-obligation-dependencies.puml) shows the main gates.

A checked precursor in the **Island** column is relevant evidence, not completion of that row. The four rightmost columns deliberately separate **G** generic theorem, **I** concrete kernel/operation instance, **E** enforced checker or validator, and **R** executable Rust correspondence. `P` means only a narrower scoped precursor currently exists; `O` means the row's target is open; `—` marks a review or integration task without that proof level. No `P` may be promoted to a completed target without reviewing theorem statements, all transitive premises, the selected arithmetic/observation profile, and a current verifier receipt. In particular, a checked generic theorem does not fill I, E, or R. No row below claims a completed production CBC chain.

The **Contract** codes are fields of the [CBC operation contract](../theory/metric-automata-cbc-obligations.md#contract-dimensions): D = validated domain; N = numerical authority; S = captured snapshot and original identities; R = rank and tie policy; W = witness; B = budgets, work and storage; O = public observations. The target column names the exact work item and its proof or evidence obligation. Rows covering design, models, controls, and review are retained so no later theorem can silently lack its supporting gate.

**Source codes:** STR = [string transducer](../../src/transducer/); BD = [bounded outcomes/ledger](../../src/time_series/bounded.rs); EL = [elastic walker](../../src/time_series/elastic/walker.rs); TW = [physical-time TWED index](../../src/time_series/timestamped_twed_index.rs) and [score](../../src/time_series/timestamped_twed.rs); AU = [temporal automata](../../src/time_series/automaton/); NUM = [machine cost operations](../../src/time_series/automaton/cost.rs), [vector scores](../../src/time_series/vector.rs), and selected exact scorer; AL = [alignment and witness scoring](../../src/time_series/alignment.rs); DOC = theory, verification, and pgmcp study artifacts. A code names the source family to instantiate, not an already proved mapping. Where the selected executable route is not yet fixed, the source code denotes candidate surfaces only and I/R remain open.

**Existing islands:** CC = [CertifiedContracts.v](temporal_automata/theories/CertifiedContracts.v); CME = [CertifiedMetricExecution.v](temporal_automata/theories/CertifiedMetricExecution.v); CSS = [CertifiedSearchSession.v](temporal_automata/theories/CertifiedSearchSession.v); CRP = [CertifiedRegionPartition.v](temporal_automata/theories/CertifiedRegionPartition.v); CSSp = [CertifiedStructuralSplit.v](temporal_automata/theories/CertifiedStructuralSplit.v); RC = [RangeCertificates.v](temporal_automata/theories/RangeCertificates.v); ES = [ElasticSnapshot.v](temporal_automata/theories/ElasticSnapshot.v); EWR = [ExactWorkspaceResources.v](temporal_automata/theories/ExactWorkspaceResources.v); LPO = [LazyProductOperations.v](temporal_automata/theories/LazyProductOperations.v); LWF = [LazyWeightedFrontier.v](temporal_automata/theories/LazyWeightedFrontier.v); OTR = [OrderedTheoryRefinements.v](temporal_automata/theories/OrderedTheoryRefinements.v); LEV = [LevDistance.v](core/theories/Core/LevDistance.v); WCF = [WeightedCostFloat.v](core/theories/Conformance/WeightedCostFloat.v); TP = [TwedProperties.v](twed/theories/Metric/TwedProperties.v); TPI = [TimestampedProductIndex.v](twed/theories/Metric/TimestampedProductIndex.v); TMT = [TimestampedMetricTransfer.v](twed/theories/Metric/TimestampedMetricTransfer.v); TSP = [TwedSourceMetric.v](twed/theories/Metric/TwedSourceMetric.v); TLA-C = [certificate replay model](tla/MetricCertificateReplay.tla); TLA-R = [range cursor model](tla/RangeCursorOwnership.tla); TLA-L = [lexicographic kNN model](tla/LexicographicKnn.tla). A finite TLA model in this list is a scoped control, never a generic proof of unbounded source behavior.

**External** names a nonlocal premise or primary specification: the published TWED statement and recurrence (`TWED-primary`, used as definitions/specification, never imported as the theorem being proved), binary64 primitive semantics and relevant Flocq results (`Flocq/IEEE`), or a metric triangle premise for NC-1. `local` means no additional external theorem is identified; it does not mean local premises are discharged. Machine TWED rows inherit Flocq/IEEE obligations when their bounds are compared with Rust binary64 scores. Task-scoped labels such as `N-TWED` and `TWED-sequence-metric` identify new candidate theorems; inherited schema IDs retain LOCPA's spelling. E denotes an accepted certificate or runtime/build admission gate, not merely a Rocq compile. Enforcement names that gate to audit or build. The [baseline evidence audit](CBC_BASELINE_EVIDENCE.md) and [observation](CBC_OBSERVATION_PROFILES.md), [numeric](CBC_NUMERIC_AUTHORITY.md), [result](CBC_RESULT_WITNESS_CONTRACT.md), and [resource](CBC_RESOURCE_EVENT_CONTRACT.md) contracts supply the detailed premises.

cannot discharge the TWED sequence-metric claim. The `cbc-03-cut` precursor
addresses generation retention, not a complete dependency cut. The
`cbc-07-witness` precursor addresses local trace replay and reservation, not
the checkpoint/replay resource theorem.

## Evidence rule and negative control

A [metric-labeled wrapper or marker](../../src/time_series/metric_domains.rs) can restrict admitted constructors, but it does not prove the score recurrence, binary64 metric laws, or that a query returns every eligible original. A [snapshot hash](../../src/time_series/elastic/walker/snapshot.rs) binds bytes or detects drift; it cannot prove a transition, lower bound, or ranking theorem. A [differential/property test](../../tests/proptest_timestamped_twed_metric.rs) covers its sampled executions; it cannot fill a universal semantic-proof cell or an untested failure path. All three may support a concrete instance after a separate proof of what they enforce. A mutant that replaces the G column with any one of these artifacts is rejected by the stage rule above; a mutant that treats a scoped G proof as R is likewise rejected. The manifest's `trusted` file status is necessary evidence about checked terms, not a statement of Rust correspondence.

A completed row requires exact theorem names and checked premises, the concrete domain and arithmetic operation graph, an accepted implementation/certificate relation where applicable, and source-to-model evidence for the chosen executable. A model or test receipt must state its finite bounds or generator scope. The dependency diagram has arrows between obligations, not logical implications from file existence. Refresh this matrix when a task is verified or a new theorem task is added, while leaving the formal manifest as the authority for artifact status.
